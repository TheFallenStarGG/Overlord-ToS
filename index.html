Quick start

  1. Invite the bot (you need Manage Server).
  2. Run !!help and !!tutorial.
  3. Optional: !!settings board #channel for the living realm board.
  4. Optional: !!settings events #channel for the announcement feed.

Permissions

The invite does not request Administrator.
