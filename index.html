The Overlord

A Discord bot for virtual economy, games, world events, and server entertainment. Free to use. Built for communities that want something to play with — not just another utility bot.

Invite to Discord Support server

Commands start with !! — try !!help after inviting. By using The Overlord you agree to the Terms of Service and acknowledge the Privacy Policy.

Getting started

  1. Invite the bot with the button above (Manage Server permission required to add bots).
  2. In any channel the bot can see, run !!help.
  3. Optional: set an announcements channel with !!events-channel #channel (needs Manage Server).

Features

  • Economy — coins, work, dailies, trading, and gambling-style mini-games
  • Games — Wordle, duels, board games, ranked play, and more
  • World events — Gazette, bosses, decrees, and server announcements
  • Progression — inventory, pets, combat loadouts, and related systems

Permissions

The invite requests only what the bot needs to function. It does not ask for Administrator.

  • View Channel
  • Send Messages
  • Embed Links
  • Read Message History
  • Add Reactions

Prefix commands need the Message Content Intent (already enabled by the bot owner in the Discord Developer Portal). Setting an events channel with !!events-channel requires Manage Server for the member running the command — not for the bot.
