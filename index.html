Rule the vibe — not a homework RPG

The Overlord is a Discord bot for server atmosphere, a light coin economy, and optional games. Chat, check the realm board, or go all-in on duels and stocks — your choice.

Add to Discord Source code

Prefix !! · Slash commands exist but are experimental · Not affiliated with Discord Inc.

For everyone (including “I don’t play Discord games”)

  • Today in the Realm — one living board (weather, decrees, bounties, headlines). Follow the story without grinding.
  • Chat & status — talk in the server; optional ranks, titles, and Overlord personality.
  • Casual coins — daily/work when you feel like it. No mandatory raid schedule.

If you do want systems

  • Economy — work, shop, trade, fishing, mining, crafting, stocks
  • Games — duels, bosses, Wordle-style and board games, ranked play
  • World — weather, decrees, events, bounties, rebellion, Gazette
  • Crafting — !!craft for food and tools; !!forge for weapons and armor

Quick start

  1. Invite the bot (you need Manage Server).
  2. Run !!help and !!tutorial.
  3. Optional: !!settings board #channel for the living realm board.
  4. Optional: !!settings events #channel for announcement feed.

Permissions

Invite does not request Administrator. Typical needs:

  • View Channel, Send Messages, Embed Links
  • Read Message History, Add Reactions
  • Manage Roles — only if you use role-linked shop titles

Message Content Intent is required for prefix commands (configured by the bot owner).
