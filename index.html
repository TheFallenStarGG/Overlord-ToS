The Overlord

A bot that runs a little economy and a shared “realm” in your server — weather, events, bounties, stocks, the usual chaos. You can ignore most of it and still check the board, or dig into crafting, duels, and the market.

Open source on GitHub. Slash commands exist but are still rough — !! is the main way to use it.

What it actually does

  • 🏰

    Realm board

    One message that updates itself: weather, active events, bounty, throne, market news. Set it with !!settings board #channel. Or just run !!board whenever.

  • 🪙

    Coins & stuff

    Daily, work, shop, fish, mine, craft, trade. Stocks exist and can go bankrupt — don’t put in what you can’t lose.

  • ⚔️

    Combat & games

    Duels, bosses, forge gear, a few minigames. Optional. Nobody has to participate.

  • 📜

    Server events

    Decrees, weather, bounties, rebellion meter, a daily Gazette. Feed goes to a channel you pick under settings.

Explore the site

    First five minutes

    1. Invite the bot (you need Manage Server).
    2. Type !!help in a channel it can see.
    3. Admins: !!settings for events channel, level-ups, realm board, etc.
    4. !!tutorial if you want the in-bot walkthrough.
