Privacy Policy

Last updated: October 10, 2026

This Privacy Policy explains what information The Overlord (“the Bot”) collects, how it is used, where it is stored, and your choices. It applies when you use the Bot in any Discord server.

The Bot is operated by the Bot’s operator (“we,” “us,” or “Operator”). Discord, Inc. is a separate company and has its own Privacy Policy.

1. Who this applies to

This policy applies to anyone who interacts with the Bot (members, moderators, and server owners) and to Discord servers where the Bot is installed.

2. Information we collect

We collect only what is needed to run the Bot. We do not ask for email addresses, phone numbers, or real names through the Bot’s normal gameplay commands. If you contact us by email or send feedback/report text, you may choose to include extra details yourself.

2.1 From Discord

When you use the Bot, Discord provides technical identifiers and context, such as:

  • Discord user ID
  • Discord server (guild) ID and channel IDs needed for features you use
  • Role IDs when a server links a shop title to a Discord role
  • Message content when you run a command or when a feature must read a message to work (for example, a game guess or a confirmation like “yes”)
  • Basic public profile fields Discord exposes to bots (such as username), when needed for display
  • Account age signals Discord exposes, used only for abuse prevention (for example, very new accounts moving large amounts of virtual currency)

2.2 Gameplay and progression (per server)

Economy and most progression are stored separately for each Discord server. This may include:

  • Virtual balances, inventory, pets, combat stats, quests, prestige, and other progression
  • Game results, cooldowns, rankings, seasons, and related timestamps
  • Stocks, companies, muscle, weather, world events, wars/alliances, and similar feature state
  • Lottery, tournament, and leaderboard-related data

Virtual currency and items have no real-world monetary value. Some features may also show aggregated or cross-server rankings where the Bot explicitly offers a global leaderboard.

2.3 Server settings (configured by admins)

When server staff use setup commands, we may store:

  • Channels for events, level-ups, games, reports, or other features
  • Channels or categories marked as ignored (no XP / quieter behavior)
  • Toggles such as gambling or robbing on/off
  • Commands disabled for that server
  • Custom shop titles (name, price, description) and optional linked Discord role IDs

2.4 Reports, feedback, and owner inbox

If you use commands such as report or feedback, we store and deliver the text you submit, along with your user ID, approximate time, and server context, to a channel chosen by the Operator so issues can be handled. Do not include passwords, tokens, or sensitive personal data in those messages.

2.5 Safety and moderation data

To reduce abuse we may store or process:

  • Short-term signals about command spam or suspicious coin movement between accounts
  • Blocks of user IDs or server IDs (blacklist), which may include a reason, who applied the block, and when
  • Operational logs (errors, diagnostics, limited command activity) for reliability and security

Logs and short-term abuse signals are for operating and protecting the Bot. They are not used to build advertising profiles.

2.6 What we do not intentionally collect

  • Payment card details (the Bot does not process real-money payments)
  • Precise GPS location
  • Government ID numbers

2.7 Public website

The Bot’s website publishes data from the Bot: the changelog, the command list, a game wiki, a status page, leaderboards, a servers page, and a Server Wars page. The leaderboards, servers page, and wars page include every server that uses the Bot, unless that server’s admins have turned this off (requires the Manage Server permission).

For included servers and users this can show: Discord display names or usernames; virtual-currency totals and net worth; XP, levels, prestige, daily streaks, and jobs worked; duel, boss, and ranked-game statistics; season scores and past season results; server names, icons, and member counts; each server’s top players, war results, and the current ruler and active events of its realm. We do not publish user IDs or server IDs on the website; server links use scrambled codes instead. The status page shows the Bot’s uptime, response time, number of servers it is in, and any outages. Anyone on the internet can view these pages, and search engines or archive services may keep copies.

You can hide yourself at any time with the Bot’s !!webhide command. Hidden users are left out of every website leaderboard, server page, and past-season result at the next update (about every 15 minutes). Server admins can remove their server with the Bot’s settings command. We cannot remove copies that other sites have already saved.

3. How we use information

We use the information above to:

  • Run commands, games, economy, events, and server features
  • Remember progress and per-server settings
  • Apply optional Discord roles when a custom title is linked to a role and purchased or equipped
  • Prevent spam, exploits, farming abuse, and fraud
  • Handle reports and feedback
  • Debug problems and improve reliability
  • Respond to support or data requests
  • Comply with law where required

We do not sell your personal data. We do not use Bot data for third-party advertising.

4. AI features

Some optional features (for example, Gazette-style text) may send limited prompts to third-party AI providers so the feature can generate a response. Prompts may include gameplay context needed for that feature. Do not put sensitive personal information into commands that trigger AI output.

Those providers process data under their own terms and privacy policies.

5. Where data is stored and who processes it

Depending on how the Bot is hosted, data may be processed by:

  • Discord — platform that delivers messages and interactions
  • Bot hosting provider — runs the Bot process
  • Database provider (for example, a cloud SQL / libSQL service such as Turso) — stores economy, settings, and related data
  • AI API providers — only when an AI-powered feature is used
  • GitHub — hosts the website and the public data files it displays (leaderboards, servers, wars, wiki, commands, status, and changelog)

These providers may process data in different countries. By using the Bot, you understand that data may be transferred to and stored in locations where our providers operate.

6. Retention

  • Gameplay and economy data for a server is kept while the Bot is used there, until deleted as described below
  • Server settings are kept while relevant, or until cleared or the server data is wiped
  • If the Bot is removed from a server, we schedule deletion of that server’s stored Bot data after a retention period of about 30 days (unless needed longer for security, abuse handling, or legal reasons)
  • Server admins can request an immediate wipe with the Bot’s data-deletion command (subject to confirmation and permissions)
  • Moderation blocks may remain until removed by the Operator
  • Logs and short-term abuse signals are kept only as long as reasonably useful for operations, security, or dispute handling
  • Report/feedback content is kept as long as needed to handle the submission

7. Sharing

We share data only when necessary:

  • With service providers that host or operate the Bot (under their agreements with us)
  • When required by law, legal process, or to protect rights, safety, or security
  • If the Bot project is transferred, data may move with it under similar protections
  • Publicly on the Bot’s website, for servers and users included in the website leaderboards (see section 2.7)

Other server members may see public Bot output in Discord (for example, game results, leaderboards, or event posts). Linked Discord roles are visible according to that server’s role settings.

8. Your choices and data deletion

  • Stop using the Bot: do not run commands; server owners can remove the Bot
  • Server wipe: admins with Manage Server may use the Bot’s delete-data command to permanently erase that server’s Bot data after confirmation
  • Removal: removing the Bot starts the automatic retention countdown for that server’s data
  • Request deletion: contact us with your Discord user ID (and server ID if relevant). We will process reasonable requests to delete or anonymize stored Bot data, subject to backups, security logs, blacklist/abuse records, and legal obligations
  • Access / correction: most data is tied to Discord IDs and game state; contact us if you need help understanding what we store about your ID

Global or cross-server features (if any) and Operator-side moderation records may not be fully removed by a single server wipe.

9. Security

We take reasonable technical and organizational measures to protect data (such as restricting access to hosting and database credentials). No system is perfectly secure. You use the Bot at your own risk.

10. Children

The Bot is intended for users who are allowed to use Discord. We do not knowingly collect personal information from children under 13 (or under the minimum age in your country). If you believe a child has provided data through the Bot, contact us and we will take appropriate steps to delete it.

11. International users

If you use the Bot from outside the country where the Operator or providers are located, your information may be processed in other countries that may have different data-protection rules.

12. Changes to this policy

We may update this Privacy Policy from time to time. The “Last updated” date will change when we do. Continued use of the Bot after an update means you acknowledge the revised policy. When changes are significant, we may also note them in the Bot or support channels when practical.
